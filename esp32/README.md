# ESP32 Robot Control

This module is responsible for microcontroller-based robotic control.

## Hardware
- ESP32
- PCA9685 servo controller
- TB6612FNG motor driver
- Hexapod servos and drive motors

## Responsibilities
- Receive movement commands
- Control the relevant actuators
- Support communication with the Raspberry Pi
- Implement safe stopping behavior

## Status
Firmware and hardware integration are under development and testing.

Exact wiring and firmware behavior should be verified against the current hardware before deployment.
