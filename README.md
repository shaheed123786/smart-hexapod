# Smart Agrobot 🤖🌱

### AI-Based Agricultural Robotics | Embedded Systems | Computer Vision

## About the Project

Smart Agrobot is an agricultural robotics prototype focused on integrating Artificial Intelligence, computer vision, embedded systems, and robotic control to support crop and weed detection and future automated weed-control operations.

## Technologies

- **Raspberry Pi:** Edge computing and camera integration
- **YOLO11n:** Object detection
- **Python and OpenCV:** Computer vision and image processing
- **ESP32:** Microcontroller-based robotic control
- **PCA9685:** Servo control
- **Hexapod Robotics:** Multi-legged robotic platform

## System Architecture

Camera → Raspberry Pi → AI-Based Detection → ESP32 → Robot Movement

## Development Goals

- Detect selected crops and weeds using computer vision.
- Integrate AI inference with embedded hardware.
- Control robotic movement using a microcontroller.
- Develop a reliable weed-control mechanism.
- Test and improve performance under different conditions.

## Current Status

Prototype under development. Individual components and system integration are being tested.
